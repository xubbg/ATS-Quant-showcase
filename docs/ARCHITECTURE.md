# ATS-Quant 技术展示仓库 — 架构总览

> 本文档为**脱敏版**架构说明，仅描述展示仓库内的可视化组件与其设计理念。
> 商业产品（账户、授权、云端、交易接入、AI、策略引擎）的架构细节不在此公开。

## 1. 设计理念

ATS-Quant 的桌面端用户界面遵循**前后端解耦**原则：

- **可视化层（本仓库）**：纯浏览器端 Canvas 渲染，负责 K 线、指标、交互、主题
- **业务层（商业版本）**：交易、策略、风控、账户、授权等，运行在独立进程中

本仓库的组件是可视化层的一次完整实现示例，可作为高性能金融图表的参考实现。

## 3. 关键设计

### 3.1 渲染引擎（render-engine）

- 单 Canvas 主循环 + 脏矩形区域重绘，控制大屏数据量下的渲染成本
- 面板（pane）由 `pane-manager` 管理，支持多指标联动缩放

### 3.2 指标流水线（indicator-pipeline）

- 指标以**注册表 + 流水线**组织：注册 → 参数化 → 计算 → 输出到渲染层
- 每个指标独立模块（`indicators-*.js`），新增指标无需改动渲染核心
- `indicator-math` 提供共享数学原语，避免重复实现

### 3.3 交互与覆盖层

- `interaction-engine` 统一处理鼠标 / 键盘 / 触摸
- `crosshair-layer` 十字光标、`drawing-manager` 绘图工具、`overlay-layer` 文本/标记覆盖层分层渲染

## 5. 与商业版本的关系

本仓库展示的是商业产品桌面端中**可视化层**的独立实现。商业版本在可视化层之上还包含：
账户与授权、交易接入、策略与风控引擎、云端服务等**不在此公开**的模块。
